# **🏴‍☠️ Btrfs Root Hunter & Rescuer**

**Автоматизированный инструмент для цифровой криминалистики и аварийного восстановления Btrfs.**  
Когда файловая система "умирает", а суперблоки молчат — в игру вступает **Root Hunter**. Скрипт игнорирует поврежденную таблицу маппинга и сканирует "сырой" диск в поисках уцелевших исторических следов (транзакций), позволяя вытащить данные из прошлого.

## **💀 Проблема**

Вы столкнулись с классическим "Btrfs Meltdown":

* mount отказывает в доступе.  
* btrfs check кричит о chunk tree error или checksum verify failed.  
* Стандартные утилиты восстановления (rescue super-recover) бессильны.

## **💊 Решение**

**Btrfs Root Hunter** автоматизирует рутинный процесс перебора "поколений" (generations):

1. **Deep Scan:** Сканирует поверхность диска с помощью btrfs-find-root.  
2. **Sort & Filter:** Отсеивает мусор и сортирует транзакции от новейших к старейшим.  
3. **Simulation:** Позволяет "заглянуть" внутрь каждой версии файловой системы без монтирования (Dry Run).  
4. **Extraction:** Вытаскивает файлы, используя найденный здоровый корень.

## **🛠 Установка**

Клонируйте репозиторий и дайте права на выполнение. Никаких зависимостей, кроме стандартных btrfs-progs.  
git clone \[https://github.com/M0NDsuChTiG/btrfs-root-hunter.git\](https://github.com/M0NDsuChTiG/btrfs-root-hunter.git)  
cd btrfs-root-hunter  
chmod \+x btrfs\_magic.sh

## **💻 Использование**

### **🕵️‍♂️ Режим "Разведка" (Scanner Mode)**

Быстрый поиск живых корней. Скрипт покажет список файлов, которые он видит, но **не будет** ничего копировать. Идеально для диагностики.  
sudo ./btrfs\_magic.sh /dev/sdX1

### **🚑 Режим "Спасение" (Recovery Mode)**

Как только вы убедились, что файлы видны, запускайте эвакуацию данных.  
**ВАЖНО:** Папка назначения должна находиться на **ДРУГОМ** физическом диске\!  
sudo ./btrfs\_magic.sh /dev/sdX1 /media/user/backup\_drive/restored\_files

## **⚙️ Требования**

* **OS:** Любой Linux дистрибутив (Debian, Arch, Fedora, Mint).  
* **Core:** Bash 4.0+.  
* **Deps:** Пакет btrfs-progs (должны быть доступны команды btrfs и btrfs-find-root).  
* **Access:** Root / Sudo привилегии (для прямого доступа к блочному устройству).
