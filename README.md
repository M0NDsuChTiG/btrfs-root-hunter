# **🔍 Btrfs Root Hunter & Rescuer**

**Скрипт аварийного восстановления данных для файловой системы Btrfs.**  
Этот инструмент предназначен для ситуаций, когда:

* Файловая система Btrfs не монтируется (mount выдает ошибку).  
* btrfs check сообщает о критических ошибках (например, chunk tree error).  
* Стандартные методы восстановления не помогают.

Скрипт автоматизирует поиск уцелевших "корней" (tree roots) файловой системы и позволяет восстановить файлы из старых транзакций.

## **🚀 Возможности**

* **Автоматический поиск:** Сканирует диск с помощью btrfs-find-root.  
* **Сортировка:** Проверяет транзакции от самых новых к старым.  
* **Интерактивный режим:** Показывает список файлов перед восстановлением, чтобы вы убедились, что данные читаемы.  
* **Безопасность:** Работает в режиме ro (read-only) по умолчанию, ничего не записывает на поврежденный диск.

## **📋 Требования**

* Linux (Debian, Ubuntu, Mint, Fedora, Arch и др.)  
* Bash  
* Пакет btrfs-progs (содержит утилиты btrfs и btrfs-find-root).  
* Права суперпользователя (sudo).

## **🛠 Установка**

1. Склонируйте репозиторий или скачайте скрипт:  
   git clone \[https://github.com/ВАШ\_НИКНЕЙМ/btrfs-root-hunter.git\](https://github.com/ВАШ\_НИКНЕЙМ/btrfs-root-hunter.git)  
   cd btrfs-root-hunter

2. Сделайте файл исполняемым:  
   chmod \+x btrfs\_magic.sh

## **📖 Использование**

### **1\. Режим "Разведка" (Без копирования)**

Позволяет быстро проверить, видит ли скрипт какие-либо файлы.  
sudo ./btrfs\_magic.sh /dev/sdX1

### **2\. Режим "Спасение" (Восстановление данных)**

**Важно:** Указывайте папку на **ДРУГОМ** физическом диске.  
sudo ./btrfs\_magic.sh /dev/sdX1 /media/user/backup\_drive/restored\_files
